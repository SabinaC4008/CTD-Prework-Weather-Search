# CTD-Prework-Weather-Search
Sabina Chauhan's Submissions for Code The Dream's Fall 2026 Web Development Track. This is the Advanced Pre-Work. A simple weather app with a few features like Temperature, Weather Condition and UV Index.
---
Hello! This is my project submission for the Advanced Pre-Work in CTD Web Development Track. 

It's a basic weather website that can show temperature, weather conditions, and max uv levels. I used the Open-Meteo API for forcasting the various weather data and geocoding the location search. 

When a location's max UV level exceeds 3, the website will showcase a warning. 

I used React + Vite to build my website so the file structure is a bit different from the one recommended. But not too much. 

## Here is a guide to find the required files/structure:
- HTML File: That is index.html at the root of the repository 
- CSS File: This is the index.css file that can be found in the src folder. 
- Javascript: This is the App.jsx file that can be found in the src folder as well. A lot of the code and work is in here. 

## Instructions to run the code
Because this website has not been deployed, to run the website download the files/make a local clone
1. Download files/Local Clone 
2. Open main folder with project
3. Open the terminal in the root directory 
4. Run 'npm install' to install dependency
5. Run 'npm run dev' to start website on local host
6. Enter the location you want weather data from. Click the buttons to determine what type of data you want.
